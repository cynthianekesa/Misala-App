# Project Setup

To set up the environment and run the project, follow the following step:

1. Clone the repository

```bash
git clone https://github.com/cynthianekesa/Misala-App
cd Drone Simulation
Open the ipynb file in gooogle collab/jupyter and run the cells to install dependencies, visualize the environment, train the agent, and visualize agent behaviour making sure to include `plant folder` and `model1.h5` in their correct paths.
```
